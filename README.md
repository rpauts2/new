# Warframe Companion

Инструменты-помощники для Warframe: рекомендации по миссиям и варфреймам, справочные данные, анализ результатов фарма и удобный интерфейс-компаньон.

## Текущий статус

Проект находится в разработке. Советник по миссиям доступен в `warframe_companion/advisor.py`. Он работает локально на Python и не требует подключения к игре.

## Быстрый запуск

Требуется Python 3.10 или новее.

```bash
python warframe_companion/advisor.py --list-missions
python warframe_companion/advisor.py --mission survival
python warframe_companion/advisor.py --mission spy --goal stealth
python -m unittest discover -s warframe_companion/tests -v
```

Если команды запускаются из корня репозитория, используйте указанные пути. В некоторых окружениях может потребоваться команда `python3` вместо `python`.

## Направление развития

- проверяемые данные о варфреймах, способностях и предметах;
- советник по реликвиям, миссиям и сборкам;
- прозрачная аналитика личных результатов;
- оверлей с таймером, заметками и состоянием источников данных;
- тесты, журналирование и простая установка под Windows.

## Принципы

- Рекомендации не являются гарантией результата и должны указывать источник и актуальность данных.
- Сторонний код можно переиспользовать только после проверки лицензии и происхождения.
- Компаньон предназначен для справки и поддержки игрока, а не для автономного прохождения миссий или обхода игровых проверок.
- Не храните пароли, токены и другие секреты в репозитории.
